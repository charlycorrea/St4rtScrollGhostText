# ST4RT Scroll Ghost Text — Archivos listos para GitHub

Esta carpeta contiene los archivos finales listos para subir/actualizar en tu repositorio de GitHub o pegar en Shopify.

## Archivos
- `st4rt-scroll-ghost-text.css`
- `st4rt-scroll-ghost-text.js`
- `st4rt-scroll-ghost-text.liquid`

## Uso recomendado
1. Reemplaza los archivos existentes en tu repo por estos archivos.
2. Si usas Shopify Theme, súbelos en:
   - `assets/st4rt-scroll-ghost-text.css`
   - `assets/st4rt-scroll-ghost-text.js`
   - `sections/st4rt-scroll-ghost-text.liquid`
3. Publica y valida en Theme Editor (`load/reorder/select`) y en móvil.

> Nota: `st4rt-scroll-ghost-text.liquid` es un archivo de **sección** y debe guardarse en `sections/`. No pegar su contenido dentro de `layout/theme.liquid`.
